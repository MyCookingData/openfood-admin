# 💻 OpenFood Admin — Dashboard de Super-Administration

Interface d'administration web et desktop Flutter pour la supervision de l'écosystème OpenFood.

## 🌟 Fonctionnalités Clés
- **Gestion des Restaurants :** Création, modération, paramétrage des commissions et liaison des comptes Stripe Connect.
- **Pilotage des Commandes :** Suivi en temps réel des flux de commandes et affectations logistiques.
- **Marketing & Promotions :** Gestion des bannières du carrousel d'accueil et génération de codes promotionnels avec suivi d'utilisation.
- **Statistiques & KPI :** Visualisation des volumes d'affaires, paniers moyens et métriques financières avec graphiques dynamiques.

## 🚀 Lancement
```bash
flutter pub get
flutter run -d chrome
```
